# סקילז של הפרויקט

סקילז שנשמרים כאן נטענים בכל סשן של Claude Code — מקומי, ווב או אפליקציה.
הם בריפו ולא מותקנים גלובלית, כי התקנה גלובלית נמחקת עם הקונטיינר.

| סקיל | מה הוא עושה | הפעלה |
| --- | --- | --- |
| `token-efficient-workflow` | עבודה בטוקנים מינימליים: חיפוש ממוקד, טווחי קריאה, עריכה כירורגית, אפס פטפוט | **בכל סשן, אוטומטית** |

## "תמיד פעיל" אינו תכונה של סקיל

סקיל נטען כשמפעילים אותו בשם או כשהתיאור שלו מתאים לשיחה. אין דגל שהופך אותו
לברירת מחדל, ולכן `token-efficient-workflow` מוכרז מתוך `.claude/hooks/session-start.sh`
(נרשם ב-`.claude/settings.json`): הפלט של `SessionStart` נכנס להקשר הסשן.

`CLAUDE.md` גובר עליו — הבדיקות, התיעוד והסיכום בעברית לבעל הריפו לא נחתכים.

## מקור

הועתק מ-`family-vault` (`.claude/skills/token-efficient-workflow`). רק הסעיף
"תחולה בפרויקט הזה" הותאם לפרויקט. הרישיון ב-`LICENSE` שליד, כפי שהגיע משם.
