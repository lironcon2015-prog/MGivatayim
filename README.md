# מכבי גבעתיים — העונה

כל העונה של הקבוצה במקום אחד: המשחק הבא, תוצאות, נתוני שחקנים, סרטונים
וקישורים. הנתונים יושבים בגוגל דרייב של המנהל; הורים ושחקנים צופים באישורו.

<https://lironcon2015-prog.github.io/MGivatayim/>

## איך זה עובד

- **הורה / שחקן** פותח את הקישור, כותב שם ("אבא של איתי") ושולח בקשה.
  אין סיסמה ואין התחברות לגוגל — המכשיר מזוהה אוטומטית.
- **המנהל** נכנס עם קוד מנהל (קישור "כניסת מנהל" בתחתית המסך), מאשר את
  הבקשה, ומאותו רגע ההורה רואה את העונה. אפשר לבטל גישה בכל רגע.
- **עדכון אחרי משחק:** מסך הניהול → "המשחק התקיים — הזנת תוצאה" → ממלאים
  את התוצאה → שמירה. נקודות, אחוזים, רצפים ופילוח בית/חוץ מחושבים לבד.

כל מכשיר מאושר בנפרד: הורה עם טלפון וטאבלט שולח בקשה מכל אחד.

## התקנה — פעם אחת, על ידי המנהל

1. **script.google.com** → New project → מדביקים את כל התוכן של
   [`tools/bridge.gs`](tools/bridge.gs) במקום מה שיש שם.
2. **Project Settings** (גלגל שיניים משמאל) → **Script properties** →
   Add script property:
   - Property: `ADMIN_CODE`
   - Value: קוד מנהל, **12 תווים לפחות**. זה הקוד שתקלידו באפליקציה.
3. **Deploy** → **New deployment** → סוג **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. מאשרים את ההרשאות שגוגל מבקש (כולל "Advanced → Go to… (unsafe)" — זה
   הסקריפט שלכם).
5. מעתיקים את **Web app URL** (מסתיים ב-`/exec`) ומדביקים אותו ב-
   [`src/config.js`](src/config.js) במקום `''` — או שולחים אותו ל-Claude.

אחרי זה נכנסים לאפליקציה → "כניסת מנהל" → הקוד → ממלאים את העונה.

**אם הקובץ `bridge.gs` מתעדכן בעתיד:** Deploy → Manage deployments → עריכה
(עיפרון) → Version: **New version** → Deploy. בלי זה הכתובת מריצה את הקוד הישן.

**להחלפת קוד המנהל:** משנים את `ADMIN_CODE` ב-Script properties. נכנס לתוקף מיד.

## פרטיות

האתר ציבורי, אבל **הנתונים לא**: שמות השחקנים והתוצאות יושבים בדרייב של
המנהל ומוגשים רק למכשירים שאושרו. הריפו עצמו מכיל רק קוד.
