# Fonts

Served with the app (see the Fonts block at the top of `styles.css`), so the
first paint never waits on another host and the app keeps its type offline.

| File | Family | Script | Source |
|---|---|---|---|
| `assistant-hebrew.woff2`, `assistant-latin.woff2` | Assistant (one variable file, every weight) | Hebrew, Latin | Google Fonts |
| `rubik-hebrew.woff2`, `rubik-latin.woff2` | Rubik (one variable file, every weight) | Hebrew, Latin | Google Fonts |

Both families are licensed under the SIL Open Font License 1.1:
